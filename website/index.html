Babu Studio

Record your capture card, webcam and microphone in sync, then export landscape and portrait videos in one go.

Free · macOS 12 or newer · All releases

Not sure which one? Click the Apple menu → About This Mac. If it says “Chip: Apple M…”, choose Apple Silicon. If it says “Processor: Intel”, choose Intel.

Install

  1. Download the .dmg that matches your Mac.
  2. Open the .dmg and drag Babu Studio into Applications.
  3. First launch: macOS will warn that it can’t verify the app. Follow Allow the app to open below. You only do this once.
  4. Grant access to the camera and microphone when asked, so the app can list and capture your devices.

FFmpeg is included. You don’t need to install anything else.

Allow the app to open

Babu Studio is free and isn’t notarized by Apple yet, so macOS Gatekeeper blocks the first launch. The app is open source, and you can read the code in the repository. Pick the option for your macOS version.

macOS 15 Sequoia or newer

  1. Open Babu Studio from Applications. Click Done on the warning.
  2. Open System Settings → Privacy & Security and scroll to Security.
  3. Next to “Babu Studio was blocked…”, click Open Anyway and confirm with your password or Touch ID.
  4. Click Open when asked again.

macOS 14 Sonoma or older

  1. In Applications, right-click (or Control-click) Babu Studio.
  2. Choose Open, then click Open in the dialog.

Terminal (any version)

If the steps above don’t work, remove the download quarantine flag:

xattr -dr com.apple.quarantine "/Applications/Babu Studio.app"

Don’t change “Allow applications from” to “Anywhere”. Only the single app needs to be allowed, as above.

Security and verification

Every release is built from the public source by GitHub Actions, scanned for malware, and published with checksums. You can check your download yourself.

  • Malware scan: each release is scanned with ClamAV, and the log is attached as clamav-scan.log.
  • VirusTotal: when enabled, the release notes link to the VirusTotal report for each installer. See the latest release. An unsigned open-source app may get a flag or two from a few engines; these are usually false positives.
  • Checksums: compare your download with SHA256SUMS.
  • Build provenance: confirm the file was built by this repository’s workflow.
shasum -a 256 ~/Downloads/Babu-Studio-arm64.dmg
gh attestation verify ~/Downloads/Babu-Studio-arm64.dmg --repo babu-studios/babu-studio-app

Troubleshooting

  • “Babu Studio is damaged and can’t be opened”: run the Terminal command above.
  • No camera or microphone listed: open System Settings → Privacy & Security → Camera / Microphone and turn on Babu Studio, then restart the app.
  • Wrong download: the Intel build runs on Apple Silicon only through Rosetta and is slower. Use the build that matches your chip.
  • Still stuck? Open an issue.
