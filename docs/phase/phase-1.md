# Phase 1: Foundation and App Setup

## Goal
Set up the base Mac desktop app and project structure so the team can start building the recording workflow.

## Scope

| Item | Task | Deliverable |
|---|---|---|
| Project setup | Create React + TypeScript app with Vite | Working frontend shell |
| Desktop shell | Integrate Tauri for macOS packaging | Desktop app foundation |
| Native setup | Configure macOS build and app permissions | Run app on Mac |
| Design system | Create basic app layout and navigation | Dashboard shell |
| Docs | Add product and architecture notes | Shared project understanding |

## Checklist
- [ ] Initialize frontend app
- [ ] Add Tauri project configuration
- [ ] Create basic app layout
- [ ] Add sidebar/navigation for capture, export, and library
- [ ] Configure Mac build settings
- [ ] Set up project folder structure
- [ ] Document app goals and architecture

## Exit criteria
- App launches on Mac
- App has a clean main dashboard
- Team can start feature development in a consistent structure
